# v0.4 Slice — Engineering Defaults + Deterministic VCS

## Goal

Preserve the two-prompt/low-question development experience while making the harness general enough for WordPress, scraping, and automation work.

## In scope

- routine engineering defaults and rule precedence;
- zero routine-question budget;
- automatic ecosystem skill binding;
- consolidated WordPress Way;
- deterministic Git controller using existing machine authentication;
- version-control safety regression tests;
- quality benchmark definition.

## Out of scope for this first proof

- remote repository creation/deletion;
- merge/release/deployment;
- installing system runtimes;
- rewriting the control plane in Python;
- embedding BMad/BMad Loop;
- generated-project copy/handoff of v0.4 controls (next integration slice after proof);
- running live providers or spending credits.

## Proof condition

GitHub Actions passes on Node 20/22/24 with the existing suite plus VCS regressions, `npm run control:verify`, and `npm run memory:resume`. Then reconcile the active task/current state to completed and proceed to generated-project integration.
